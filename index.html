O que são bibliotecas?

Analise de Dados

pandas

Biblioteca que facilita a manipulação e análise de dados. Com ela, é possível trabalhar com tabelas e conjuntos de dados de maneira eficiente, realizando operações como filtragem, agrupamento e transformação.

Mais sobre pandas

NumPy

Biblioteca que fornece suporte para matrizes e arrays multidimensionais, além de uma grande coleção de funções matemáticas para operações sobre esses arrays. NumPy é amplamente utilizado em análise de dados, aprendizado de máquina e outras áreas que envolvem cálculos numéricos eficientes.

Mais sobre scikit-learn

scikit-learn

Biblioteca de código aberto para aprendizado de máquina em Python. Ela foi desenvolvida para facilitar a implementação de algoritmos de machine learning e é construída sobre outras bibliotecas populares, como NumPy, SciPy e Matplotlib

Visualização de Dados

Matplotlib

Biblioteca de visualização de dados para Python, amplamente utilizada para criar gráficos e figuras de maneira simples e eficiente. Com ela, você pode gerar gráficos de linha, barras, dispersão, histogramas, gráficos de pizza e muito mais.

Aprendizado de Máquina

TensorFlow

biblioteca de código aberto desenvolvida pelo Google para aprendizado de máquina e computação numérica. Ele permite a criação e o treinamento de modelos de inteligência artificial, incluindo redes neurais profundas, de forma eficiente e escalável.

Mais sobre TensorFlow

PyTorch

Biblioteca de aprendizado profundo de código aberto baseada em Python, amplamente utilizada para construir e treinar redes neurais. Ele combina a flexibilidade da linguagem Python com uma API intuitiva, permitindo que cientistas de dados e pesquisadores desenvolvam modelos de inteligência artificial de forma eficiente1.
